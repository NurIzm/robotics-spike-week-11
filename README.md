# Кисть

Урок 11 кружка робототехники: манипуляторы и автономия на LEGO SPIKE Prime. Собираем робот-руку третьей модели: кисть с тремя пальцами, тремя моторами и тремя датчиками. Сравниваем двухпальцевый и трёхпальцевый захваты, улучшаем модель и придумываем свой захват.

**Открыть урок:** https://nurizm.github.io/robotics-spike-week-11/

**Қазақша нұсқасы:** https://nurizm.github.io/robotics-spike-week-11/kk/

## Что внутри

- стартовый экран с 3D-моделью «Кисть»;
- урок: три модели одной темы, сколько пальцев нужно захвату, из чего состоит кисть, программа автора модели, как улучшить модель, планировщик своего захвата, сборка и разборка, мини-тест;
- шесть анимированных примеров из жизни, где у робота несколько пальцев;
- программа: блоки как в приложении SPIKE слева, работающая 3D-модель справа, четыре задания: допиши программу, два или три пальца, три пальца одной кнопкой, передай предмет.

Кнопка «Начать заново» на экране программы возвращает стартовую программу и стирает отметки. Она нужна перед следующим классом.

## Модель

«SPIKE Manipulator», альтернативная модель для набора LEGO SPIKE Prime 45678, автор Irwin Wu. Её нет в приложении SPIKE: инструкция в PDF у учителя. Порты: моторы пальцев A и C, мотор большого пальца E, датчик расстояния B, датчик силы D, датчик цвета F.

## Без интернета

Скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `index.html` двойным кликом, казахскую версию — `kk/index.html`. Всё работает, только шрифты будут запасными.

## Как поменять

`index.html` собирается из исходников, вручную его не правьте. Экраны лежат в `src/views`, логика в `js`, стили в `css`, исходное задание в `src/SPEC.md`.

```bash
node src/build.js
```

Логику блоков проверяет `tests/vm-check.html`: откройте его в браузере, все строки должны быть PASS.

Казахская версия лежит в `kk` и `src/kk` и собирается командой `node src/build.js kk`. Источник — русские файлы: правку в них повторите в `kk/js` или `src/kk/views`. Термины записаны в `src/kk/GLOSSARY.md`, `node src/kk/check.js` показывает текст, который остался непереведённым, а `node src/kk/code-check.js` — код в `kk/js`, который разошёлся с русским.
